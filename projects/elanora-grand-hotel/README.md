# ÉLANORA GRAND HOTEL

Luxury multi-page hotel website & room booking system.

## Tech
- HTML5
- CSS3
- Vanilla JavaScript
- Local WebP imagery
- Local SVG icons

## Pages
- `index.html`
- `rooms.html`
- `room-detail.html`
- `facilities.html`
- `dining.html`
- `gallery.html`
- `about.html`
- `contact.html`
- `booking.html`
- `booking-confirmation.html`

## Run
Open `index.html` using a local static server (for example VS Code Live Server), or deploy the folder to any static hosting service.

## Booking Demo
The booking flow is frontend-only. Availability is simulated, non-sensitive reservation state is held in memory/sessionStorage, and no real payment is processed.

Payment card data is never stored.

## Contact Form
The contact form clearly behaves as a frontend demo and does not claim that a message has been sent to a real backend.

## Images
All core visual assets are bundled locally under `assets/images/`.

## Icons
All interface icons are local transparent-background SVG files under `assets/icons/`.
